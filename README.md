# Preference centre mockup

Clickable mockup of a preference centre for three audiences: newsletter subscribers, press
contacts and staff. Static HTML, CSS and JavaScript; nothing is sent or saved anywhere.
All people and email addresses on the pages are fictitious.

Open `index.html`, or the GitHub Pages site of this repository.

- Page language: nl / fr / de / en at the top right of each page.
- Press **N** (or the *Model notes* button) to show what each section would record in Salesforce.
